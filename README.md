**Neon Harbor — Midnight Cover Studio.** Turn a photo and a caption into multi-panel poster cover art in the style of a crime saga: three original fictional characters (Rex Marlowe, Vera Night, Dex Cole) from the neon city of Neon Harbor, three layouts (Harbor Nights, Neon Grid, Midnight Strip), five colour grades, drag-to-pan framing with zoom, and PNG export in 1080×1080, 1080×1350 and 1920×1080. A static web app — no build step, no network, no account. Add your own photos or use the three sample portraits, pick a layout and a grade, write your title and tagline, and export the cover.

## Run it

```sh
python3 -m http.server 8000 --directory app
```

Then open http://localhost:8000 in a desktop browser.
